Detailed Description

A hash table implementation that maps 64-bit keys to void* values.

Uses linear probing for collision resolution and automatically resizes when load factor exceeds 0.75. Supports deletion via tombstone markers.

Note: Keys HT_EMPTY (0) and HT_TOMBSTONE (1) are reserved and cannot be used.
