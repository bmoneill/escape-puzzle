◆ locale_get()

char * locale_get ( const char *  key,
char *  buffer,
unsigned long long  buffer_size 
)

Retrieves a localized string for the given key and copies it into the provided buffer.

If the key is not found, the buffer will contain a default null string defined by LOCALE_NULL_STRING, and the function will return NULL. Otherwise, it returns a pointer to the buffer containing the localized string.

Parameters
keyThe key for the localized string to retrieve.
bufferThe buffer to copy the localized string into.
buffer_sizeThe size of the buffer.
Returns
pointer to buffer containing the localized string, or NULL if the key is not found.

◆ locale_init()

void locale_init ( const char *  locale_path)

Initializes the locale system by loading localized strings from the specified file.

The locale file should be in the format of key=value pairs, one per line.

If locale_path is NULL, it will default to "LOCALE_PATH/en_us.txt"

Parameters
locale_pathThe path to the locale file to load.
